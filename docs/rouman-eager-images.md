# 肉漫屋图片全部加载

将 [`Rouman-Eager-Images.js`](../Rouman-Eager-Images.js) 的完整内容粘贴到 Tampermonkey 新建脚本中，保存并刷新网页。

- 书籍详情页 `/books/<书籍 ID>` 和章节页 `/books/<书籍 ID>/<章节序号>` 自动加载当前页面全部图片，无需滚动
- 正文图片通过网站原有加载回调处理，保留需要 canvas 还原的图片显示逻辑
- 支持站内进入书籍、切换章节及动态插入的图片；脚本需要在页面开始加载时运行，并使用页面 JavaScript 环境
- 只加载当前页面，不预取其他章节；同时请求全部图片会增加流量和内存占用，实际完成时间取决于网络和图片服务器

正文识别依赖 `.site-reader-canvas` 和 `image_` 图片 ID；网站更改结构或加载方式后可能需要调整脚本。
